# 🧠 FreeAi Services Updater  
**Автоматический обновляющий агент для расширений браузеров**

Программа предназначена для автоматического обновления файлов браузерных расширений (Chrome, Яндекс/Опера) с GitHub. Может работать как в интерактивном режиме, так и в фоне.

---

## 📦 Возможности

- Автоматическое обновление файлов из `.zip` архива или через `git pull`.
- Поддержка автозагрузки Windows.
- Проверка обновлений программы с последующим скачиванием актуальной версии.
- Работа в тихом режиме (`--silent`) без вывода информации.
- Обнаружение типа расширения по наличию `manifest.json`.

---

## 🛠 Требования

- Windows 10 / 11
- .NET 8 Runtime (или автономная сборка)
- Git (опционально, если используется обновление через репозиторий)

---

## 📁 Установка

1. Скачайте последнюю версию `FreeAiServicesUpdateApp.exe` с [GitHub Releases](https://github.com/Processori7/update/releases). 
2. Поместите программу в папку с расширением, которое вы хотите обновлять.
3. Запустите программу:
   ```bash
   FreeAiServicesUpdateApp.exe
   ```

---

## ⚙️ Настройка

### Добавление в автозагрузку:

```bash
FreeAiServicesUpdateApp.exe --start
```
> Программа будет запускаться при входе пользователя в систему и автоматически обновлять файлы расширения.

### Удаление из автозагрузки:

```bash
FreeAiServicesUpdateApp.exe --stop
```

---

## ▶️ Режимы запуска

| Флаг | Описание |
|------|----------|
| `--start` | Запуск из автозагрузки — добавляет себя в автозагрузку (если ещё не добавлено), затем выполняет обновление в фоне |
| `--silent` | Тихий режим — ничего не выводит, работает в фоне |
| `--stop` | Удаляет программу из автозагрузки |

---

## 🔍 Как это работает

Программа проверяет наличие `.git` папки. Если она есть и установлен `git`, то выполняется команда `git pull`. В противном случае:
- Читается `manifest.json`
- Определяется тип расширения (Chrome или Яндекс/Опера)
- Скачивается соответствующий архив и заменяются файлы

---

## 🔄 Проверка обновлений программы

Если доступно новое обновление самой программы, программа предложит скачать и запустить его.

Проверка происходит через GitHub API:  
👉 `https://api.github.com/repos/Processori7/update/releases/latest` 

Скачиваемый файл: `FreeAiServicesUpdateApp.exe`

---

## 💡 Полезные советы

- Чтобы программа работала **полностью невидимо**, используйте режим `--silent`.
- Лучше всего использовать **автономную сборку** (`Self-contained`) под Windows x64/x86.
- Для отладки можно включить запись логов в файл, если нужно.

## 🧩 Разработка

Для самостоятельной сборки:

1. Убедитесь, что установлен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) 
2. Выполните:
   ```bash
   dotnet publish -r win-x64 --self-contained -c Release /p:PublishSingleFile=true
   ```
3. Полученный файл находится в:
   ```
   bin\Release\net8.0\win-x64\publish\FreeAiServicesUpdateApp.exe
   ```

По умолчанию в .scproject установлена ``` <OutputType>WinExe</OutputType> ``` - это означает, что создается приложение со скрытым окном. CMD тоже не будет видна.  Для разработки рекомендую установить``` <OutputType>Exe</OutputType> ```
